# fu-capital_contracts

NFT-collateralized lending marketplace smart contracts built for a client project during my time at Kreatorverse.

Contracts: FULoanNFT.sol represents loan positions as NFTs, and FUCapitalMarketplace.sol implements the lending marketplace logic. The priceModule folder contains supporting pricing logic, and Interfaces defines the related contract interfaces.

Getting started: install dependencies with npm install, compile contracts with npx hardhat compile, and run tests with npx hardhat test.
